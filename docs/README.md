such as `docs/ru/` and mirror the `docs/en/` file names.

Release binaries are attached to
[GitHub Releases](https://github.com/nullclaw/nllclw/releases). While the
repository is private, downloads require access to `nullclaw/nllclw`.

Before adding or updating translations, read
[en/localization.md](en/localization.md).
